# Miso

An original plush red panda, rendered as a transparent 3 × 3 sprite atlas.
Cells, read left to right and top to bottom: standing, walk A, walk B,
sitting, sleeping, carried, delighted, play bow, mischievous.

The accompanying JSON defines the reviewed source regions. The application
trims transparent margins at load time and preserves the relative scale of
the frames. Movement, breathing, anticipation, landing,
particles, shadows and toys are animated by SpriteKit.

Character art is generated with the built-in imagegen tool. See
`docs/CHARACTER-ART.md` for the production prompt and provenance.
